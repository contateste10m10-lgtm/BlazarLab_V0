BlazarLab Privado 13.11 Lite

Biblioteca de dados publicada + carregamento de arquivos locais, mantendo origem e proveniência explícitas.

## O que há de novo na 13.11

- Nova aba **Biblioteca do site** lê `biblioteca/manifest.json` e permite escolher um ou vários conjuntos pelo nome.
- `Carregar selecionados` substitui a carga multifonte ativa; `Adicionar à carga atual` acrescenta os datasets selecionados sem duplicar IDs já carregados.
- Nova aba **Meus dados locais** preserva a importação local de múltiplos CSV/TSV/TXT, pasta/ZIP e arrays NumPy (`.npy`/`.npz`). Esses arquivos não são enviados ao site.
- O catálogo é atualizado pelo botão “Atualizar catálogo”, permitindo adicionar arquivos ao repositório e cadastrar suas descrições no manifesto.
- A biblioteca contém um conjunto sintético demonstrativo para confirmar o fluxo logo após a publicação. Não representa observações astronômicas reais.
- Cada linha carregada conserva a origem do arquivo; valores ausentes não são preenchidos e as tabelas são combinadas por nome de coluna.

## Esquema do CSV completo para o modo avançado

A exportação completa usa 26 campos, nesta ordem. Campos derivados só são preenchidos quando há resultado válido; estimativas experimentais e escalas WPE são identificadas explicitamente.

```csv
fonte,janela,banda,tempo,fluxo,sampen,classe_fonte,variabilidade_robusta,modulation_index_percent,n_pontos,sigma,r_absoluto,H_X_nats_KDE_experimental,entropy_power_NX_KDE_experimental,Fisher_information_KDE_experimental,Fisher_Shannon_product_experimental,WPE_nats,CI_WPE_sum_nats_experimental,WPE_valid_scales,WPE_escala,tipo_registro,status_modulacao,limite_superior_modulacao_percent,modulacao_ic68_inferior_percent,modulacao_ic68_superior_percent,erro_fluxo
```

`tipo_registro=observacao` representa um ponto temporal da curva. `tipo_registro=escala_wpe` representa uma estimativa WPE para uma escala, e `WPE_escala`/`janela` identifica essa escala. Não interprete a coluna `janela` como janela temporal real quando ela contém apenas o índice de escala. Valores vazios significam ausente/não estimável, não zero. Um limite superior candidato de modulação permanece em `limite_superior_modulacao_percent`, separado da detecção.

## Como usar a biblioteca do site (Opção B)

1. Adicione somente arquivos públicos, sintéticos ou autorizados à pasta `biblioteca/dados/`.
2. Registre cada arquivo em `biblioteca/manifest.json`, usando um `id` único, `title`, `description`, `path` (relativo à pasta `biblioteca/`), `format`, `synthetic` e `license`.
3. Faça commit/push dos arquivos ao repositório que publica a ferramenta.
4. No site, abra a Galeria Multifonte → **Biblioteca do site** → “Atualizar catálogo”. Marque um ou mais conjuntos e clique em “Carregar selecionados” ou “Adicionar à carga atual”.
5. Confira o mapeamento das colunas e clique em “Gerar galeria completa”.

O catálogo aceita caminhos relativos dentro de `biblioteca/`. São permitidos `.csv`, `.tsv`, `.txt`, `.npy`, `.npz` e `.zip`. O site limita o manifesto a 200 entradas e cada recurso a 50 MiB. Se uma entrada for inválida, o catálogo a ignora e mostra um aviso.

## Como usar meus dados privados (Opção A)

Use a aba **Meus dados locais** para selecionar arquivos diretamente, anexar uma pasta (nos navegadores compatíveis), ou carregar um ZIP com vários arquivos. Isso não publica os dados e não os envia a um servidor. Para dados reais não autorizados para divulgação, esta é a opção recomendada.

## Importante sobre privacidade

Qualquer arquivo adicionado à biblioteca que o GitHub Pages publica será acessível pela internet, mesmo se você não criar um botão de download. Não coloque dados privados, observações com restrições ou credenciais em `biblioteca/dados/`. O repositório pode conter a pasta `biblioteca/`, mas arquivos reais privados devem permanecer locais. O catálogo é estático; não existe upload para um backend nem armazenamento privado de arquivos enviados pelo usuário.

## Estrutura da biblioteca

```text
biblioteca/
├── manifest.json
├── README.md
├── dados/
│   └── ADICIONE_SEUS_DADOS_AQUI.txt
└── exemplos/
    └── demo_multifonte_SINTETICO.csv
```

O README em `biblioteca/` explica o formato do manifesto. Não é necessário modificar o código JavaScript para cada novo dataset: basta adicionar o arquivo dentro de `biblioteca/`, cadastrá-lo no manifesto e atualizar o catálogo no site.

## Fluxos preservados

- A integração direta da análise principal calcula os quatro métodos quando necessário e encaminha os resultados à galeria sem ida e volta por CSV.
- O CSV completo continua disponível para arquivar ou levar resultados a outra sessão/dispositivo.
- A galeria mantém os campos de SampEn, Fisher–Shannon, modulação e WPE/CI quando presentes. Campos ausentes permanecem vazios; as métricas experimentais e os estados de validade continuam explicitamente identificados.
- `.npy` aceita arrays escalares, 1D, 2D e estruturas simples suportadas; `.npz` combina arrays nomeados de comprimento compatível. `dtype=object`/pickle, ZIP64, ZIP criptografado e arrays acima de duas dimensões não são importados automaticamente.

## Uso local para desenvolvimento

O catálogo integrado usa `fetch` e deve ser servido por HTTP/HTTPS. Em GitHub Pages funciona a partir do diretório publicado. Abrir `index.html` diretamente com `file://` pode bloquear o carregamento do manifesto por política do navegador.

## Limites científicos

Fisher–Shannon por KDE permanece experimental; o CI de WPE continua provisório até homologação de sua fórmula; os intervalos de modulação requerem calibração externa. A seleção de uma biblioteca não transforma dados sintéticos em observações reais nem valida automaticamente a qualidade científica de um dataset.


## Biblioteca Swift/BAT integrada na 13.11

A pasta biblioteca/dados/swift-bat contém três recursos ZIP compactos para SWIFT J0017.1+8134, SWIFT J0042.9+3016B e SWIFT J0413.3+1659. Cada recurso contém uma tabela CSV larga com uma linha por snapshot, oito colunas RATE e oito RATE_ERR, mais tempo original e metadados. Consulte biblioteca/metadados/SWIFT_BAT_157M_CONVERSAO.md antes de interpretar ou redistribuir. Recomenda-se carregar uma fonte por vez.


## Abrir uma fonte Swift/BAT da biblioteca

Na Galeria Multifonte, abra Biblioteca do site, atualize o catálogo e selecione exatamente uma curva Swift/BAT. Clique em “Abrir fonte no laboratório principal”. O arquivo CSV compactado é aberto em memória; confira o mapeamento automático de tempo, oito taxas e oito erros, e clique em Calcular. Para ver curva e métricas na galeria avançada, use “Calcular se necessário + integrar os quatro métodos”. Não precisa baixar nem reimportar um CSV. Para preservar memória, processe uma fonte por vez.
